### Perfil

- **Formación:** Desarrollador de Software graduado de la Universidad Tecnológica Nacional (UTN).
- **Proyecto Principal:** Creador y mantenedor de **[DiDent](https://github.com/FelipeIntelangelo/DiDent)**, plataforma SaaS multi-tenant para clínicas odontológicas desarrollada con **Spring Boot (Java 21)**, **Angular**, persistencia relacional con **MySQL / PostgreSQL**, integración con Google Calendar API v3 y despliegue productivo en **Oracle Cloud** y **Cloudflare**.
- **Otros Proyectos:** Creador de **[Wavelly](https://github.com/FelipeIntelangelo/Wavely)**, plataforma para streaming y consumo de podcasts ([API RESTful](https://github.com/FelipeIntelangelo/Podcast-Api-RESTful) | [Frontend](https://github.com/FelipeIntelangelo/PodcastFront)).
- **Especialidad Técnica:** Arquitecturas backend modulares con Spring Security (JWT con claims multi-tenant y control de acceso en capas), frontend reactivo basado en Angular Signals, contenedorización con Docker y despliegue en entornos Linux.
- **Intereses:** Ciberseguridad aplicada, seguridad en APIs, análisis de vulnerabilidades y automatización de infraestructura.
